# scenery — 영상 곡 대체 아트

이 폴더에 이미지(jpg/png/webp)를 넣으면, 영상(16:9) 곡을 들을 때 디스코드에 표시되는 아트로 사용됩니다.

- 곡마다 이 중 한 장이 **고정 배정**됩니다 (같은 곡 = 항상 같은 사진).
- **분위기 매칭**: 파일명에 키워드를 넣으면(`_`나 `-`로 구분), 곡 제목/가수에 그 키워드가 든 곡에 우선 배정됩니다.
  - 예: `밤_평양야경.jpg` → 제목에 "밤"이 든 곡 / `바다_원산.jpg` → "바다"가 든 곡
  - 키워드가 하나도 안 맞으면 해시로 아무 사진이나 고정 배정됩니다.
- 기본 모드(`mix` = 자동)의 판단 순서:
  1. 분위기 태그가 맞으면 → 그 사진
  2. 썸네일에 **글씨가 있으면**(윈도우 내장 문자인식으로 자동 판별) → 잘리면 훼손되므로 풍경
  3. 글씨가 없으면 → 스마트 크롭 (잘라도 해가 없음)
  `config.json` 의 `videoCover` 로 바꿀 수 있습니다 (`"scenery"` = 풍경만, `"crop"` = 크롭만).
- 태그 동의어가 내장되어 있어 정확히 같은 낱말이 아니어도 걸립니다
  (예: 파일명 태그 `밤` → 제목의 야경·새벽·달빛·별빛에도 매칭).
- 정사각(1:1)에 가까운 이미지를 권장합니다. 아니면 디스코드가 정사각으로 잘라서 보여 줍니다.
- 파일을 추가/교체한 뒤 앱을 다시 시작하면 반영됩니다 (재빌드 불필요).
- 이 폴더가 비어 있으면 임시로 무작위 실사 사진(Lorem Picsum)이 사용됩니다.

> 저작권에 문제가 없는 이미지만 넣어 주세요. 이 저장소는 공개입니다.
