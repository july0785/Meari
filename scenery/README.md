# scenery — 영상 곡 대체 아트

이 폴더에 이미지(jpg/png/webp)를 넣으면, 영상(16:9) 곡을 들을 때 디스코드에 표시되는 아트로 사용됩니다.

- 곡마다 이 중 한 장이 **고정 배정**됩니다 (같은 곡 = 항상 같은 사진).
- **분류 체계 = 시간대(필수) / 피사체(선택)**. 폴더 이름이 곧 분위기 태그입니다:
  ```
  scenery/
  ├── 낮/
  │   ├── 인공물/   1.png …
  │   └── 자연물/   1.png …
  ├── 노을/         1.png …   (하위분류 없이 바로 넣어도 됨)
  └── 밤/
      └── 인공물/   1.png …
  ```
  - 시간대: `낮` / `노을` / `밤` (필요하면 새 시간대 폴더 추가 가능)
  - 피사체: `인공물`(도시·건물·중공업…) / `자연물`(강·숲·들판·농사…) — 선택 사항
  - 파일 이름은 `1.png` 처럼 숫자만 써도 됩니다 — 태그는 폴더에서 나옵니다.
  곡 제목·가수·앨범·가사에 해당 계열 낱말이 들어 있으면 그 폴더의 사진이 우선 배정됩니다
  (두 단계가 다 맞는 사진이 한 단계만 맞는 사진을 이깁니다).
- 밤·야경·새벽처럼 겹치는 분류는 내장 동의어 사전이 한 묶음으로 취급하므로 아무 이름이나 쓰면 됩니다.
- 파일명에 키워드를 넣는 방식(`밤_평양야경.jpg`)도 똑같이 동작합니다.
- **한 사진에 여러 태그**를 붙일 수 있습니다 — 아래 셋 다 "밤+바다" 태그가 됩니다:
  - 중첩 폴더: `밤/바다/해금강.jpg`
  - 폴더 + 파일명: `밤/바다_해금강.jpg`
  - 파일명만: `밤_바다_해금강.jpg`

  태그가 **많이 일치하는 사진일수록 우선** 배정됩니다 (밤+바다 곡이면 두 태그 사진이 한 태그 사진을 이깁니다).
- 어떤 분위기에도 안 걸리면 해시로 아무 사진이나 고정 배정됩니다.
- 기본 모드(`mix` = 자동)의 판단 순서:
  1. 분위기 태그가 맞으면 → 그 사진
  2. 썸네일에 **글씨가 있으면**(윈도우 내장 문자인식으로 자동 판별) → 잘리면 훼손되므로 풍경
  3. 글씨가 없으면 → 스마트 크롭 (잘라도 해가 없음)
  `config.json` 의 `videoCover` 로 바꿀 수 있습니다 (`"scenery"` = 풍경만, `"crop"` = 크롭만).
- 태그 동의어가 내장되어 있어 정확히 같은 낱말이 아니어도 걸립니다
  (예: 파일명 태그 `밤` → 제목의 야경·새벽·달빛·별빛에도 매칭).
- 정사각(1:1)에 가까운 이미지를 권장합니다. 아니면 디스코드가 정사각으로 잘라서 보여 줍니다.
- 파일을 추가/교체한 뒤 앱을 다시 시작하면 반영됩니다 (재빌드 불필요).
- 이 폴더가 비어 있으면 임시로 무작위 실사 사진(Lorem Picsum)이 사용됩니다.

> 저작권에 문제가 없는 이미지만 넣어 주세요. 이 저장소는 공개입니다.
